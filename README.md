## 🧩 Architecture

The application follows a component-based frontend architecture.

```text
Next.js Application
        │
        ├── Pages / Routes
        │
        ├── UI Components
        │
        ├── Sections
        │
        ├── Assets
        │
        └── Styling
             │
             └── Tailwind CSS

The structure allows individual sections and components to be developed and maintained independently.
